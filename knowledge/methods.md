# AI Methods & Techniques

- [METH-001](methods/METH-001.md) | Sonnet 5.5 migration (thinking default, effort recalibrated) | Smarter than Sonnet 5, ~30% faster, same price; up to 30% cheaper per task; breaking API changes.
- [METH-002](methods/METH-002.md) | Decision models ('System One', typed decision models) | What it is: the model receives a state and some defined questions: yes or no, a choice from a list or a score. It does not write text, but returns a probability for each possibility.
- [METH-003](methods/METH-003.md) | Cockroach Labs: A pipeline of code agents in a hospital building | What it is: A pipeline of code agents with fixed roles: triage, planning, review and release. Before any merge, planning and documentation are required. Running in production for five months.
- [METH-004](methods/METH-004.md) | STEPGATE: Escalation from a small model to the cloud at the step level | A small, local model runs the agent and gives each step an uncertainty score.
- [METH-005](methods/METH-005.md) | MASS: Multi-Agent Self-Supervision | What it is: Sakana and Berkeley method. The same model is used as a solver, as someone who improves the workflow of the agent team and also as an evaluator.
- [METH-006](methods/METH-006.md) | RATED: Retrieving tools according to reliability | Semantic retrieval of tools, plus a bandit algorithm that reranks them according to successes and failures at runtime.
- [METH-007](methods/METH-007.md) | T²Mem: Memory built at query time | What it is: In advance, only light metadata is saved on each call.
- [METH-008](methods/METH-008.md) | An Empirical Study of Harness Design for Coding Agents | What it is: A controlled study. The execution loop of the code agent remains constant, and only three components are changed: planning, scope of operations and context management.
- [METH-009](methods/METH-009.md) | Beyond the Final Embedding | Memory retrieval that uses the token representations that the embedding model has already calculated.
- [METH-010](methods/METH-010.md) | Lost in Implicit Routing: collapse in routing skills | As there are more irrelevant skills, the agent stops loading the relevant skills as well, even though they are installed.
- [METH-011](methods/METH-011.md) | CarryOn: An object-based context for long-lived agents | Instead of saving the interaction history, the agent manages continuity around reusable task objects, keeping a verified record of the state.
- [METH-012](methods/METH-012.md) | Keep Your Receipts (PolyGraph): Clearing knowledge graphs | Each item in the knowledge graph that an agent builds is saved with a 'receipt', i.e. a record of the sources that support it.
- [METH-013](methods/METH-013.md) | OAR: Ownership-Aware Routing | When the tables in the organization belong to different owners, you have to choose how to send the query.
- [METH-014](methods/METH-014.md) | DKGI: Knowledge Graphs as Files | The agent writes and debugs Python tools directly on the nodes and arcs files of the knowledge graph, without a predefined graph API.
- [METH-015](methods/METH-015.md) | Decision models that share control with the LLM: JevAgentHarness and Jev-LiteMAS | Most calls to LLM in harness end with a choice of several options, for example which tool to run.
- [METH-016](methods/METH-016.md) | Agent memory as a Git repo of Markdown (Cognition Agent Memory Repo) | Devin memory = git repo of notes; MEMORY.md index per session, source-tagged lines, safe parallel merges, daily 'Dreaming' cleanup.
- [METH-017](methods/METH-017.md) | Authorization outside the model (Privacy Conductor + AFR) | LLMs can't decide who may see a document: deterministic gate on human-written policy, model only sees what the requester may see.
- [METH-018](methods/METH-018.md) | Usefulness score + threshold instead of embedding top-k (GPT Researcher) | Keep a chunk only if a usefulness score clears a threshold; 73% of kept passages relevant vs 46% with embeddings.
- [METH-019](methods/METH-019.md) | Always rerank; agentic search only once tuned (Kapa Company Knowledge Bench) | 7 retrievers on 1,000 production queries: hybrid 0.41, top-100 reranked to 15 = 0.50 for ~0.3 s and no extra tokens.
- [METH-020](methods/METH-020.md) | GraphRAG indexing cost reality check | GraphRAG on one 41-page paper with a local 27B model: ~281 calls, ~2 h; another 26-page paper +73 min; the graph is an ongoing cost.
- [METH-021](methods/METH-021.md) | FAOPs: normal forms for skills libraries (JPMorgan Chase) | Four normal forms: atomic decomposition, types, deduplication, and least privileges; Algebra for safe refactoring and parallel execution; A four-level scale that classifies if AI is needed at all.
- [METH-022](methods/METH-022.md) | Environment-Agnostic Coding Agents: The Role of Scaffolding | A small change in the prompt, 'stop and report when unsure', improves scores on the ARC-AGI-3 and the AGI Maze without a scaffold that is adapted to the environment.
- [METH-023](methods/METH-023.md) | Agentic RAG via portable skills (Airbnb) | SKILL.md + four scripts + one hybrid search tool over an LLM-written wiki: 99.2% procedure match; evidence sufficiency 83.3% vs 59.8% for production RAG.

- [METH-025](methods/METH-025.md) | INO: user corrections become retrievable knowledge nuggets | Turn factual corrections into short KB entries, test against the unchanged RAG with paraphrases, rewrite until retrieved and cited.
