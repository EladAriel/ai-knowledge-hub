# DEVX-028: Cursor cloud agents to internal MCP via Tailscale

## Summary

A new Cursor docs page shows Rollouts joining your tailnet as an ephemeral, tagged device.

## Details

That lets cloud agents reach an internal https MCP server without exposing it publicly. It's a beta that sales has to turn on, and the only source so far is the docs page.
