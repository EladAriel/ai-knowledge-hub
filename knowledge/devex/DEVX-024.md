# DEVX-024: You should know

## Summary

A built-in side agent with no tools that flags tradeoffs and risks you might miss.

## Details

It needs 2.1.287+ and a direct connection (no gateway or 'apiKeyHelper'), and it uses extra requests. Credit: Claude Code docs. /plugin enable cc-plugin-you-should-know@builtin.
