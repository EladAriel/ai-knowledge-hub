# DEVX-020: context-band

## Summary

Shows '1h-cache' or '5m-cache' and your context use above the prompt, so you can see whether your cache pin really works.

## Content

**[context-band](https://github.com/derek1ee/claude-context-band)** shows `1h-cache` or `5m-cache` and your context use above the prompt, so you can see whether your cache pin really works. It's MIT-licensed, has 0 stars and relies on an early-access hooks API, so try it on a personal machine first and leave auto-refresh off. Effort ~2 min. Credit: derek1ee.
```bash
claude plugin marketplace add derek1ee/claude-context-band
claude plugin install context-band@claude-context-band
```
