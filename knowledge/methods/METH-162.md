# METH-162: New terms (Nov 13, methods): Gemini 4 Hydrogen, Brave Search with x402, CoReMem, EGE, MULTILOOP, AgentRun, Gemini Managed Agents

## Summary

One-line mentions from the Nov 13 methods digest (no full evaluations). Atuin Threads was also listed and is covered in DEVX-081.

## Details

Gemini 4 Hydrogen: Google's fast coding model. According to Google it reaches 57% on Terminal-Bench 4.1, and it has a new thinking level named xhigh. Brave Search API with x402: agents pay per request in USDC with no API key, $5 per thousand requests. CoReMem (arXiv 2611.17316): memory for coding agents that weighs the cost of each item against its value on the next task; on ChainSWE it rose from 21.0% to 25.7%. EGE, Evidence-Governed Evolution (arXiv 2611.16378): a statistical framework for when to adopt a change the agent produced for itself, with tests that the change is not worse and with gradual rollout; theoretical only. MULTILOOP (arXiv 2611.15754): automatic harness optimization for a multi-agent system; a 4.6% improvement from only 10 examples, but orchestration failures remained. AgentRun (Parcha-ai/agentrun): an open-source platform for durable runs and self-improvement on top of an existing harness, about 690 stars. Gemini Managed Agents: you can now run the sandbox on your own infrastructure, for example E2B, Modal or Daytona; planning stays in Google's cloud. Repeats from earlier days, not listed again as new: ShadowBench-MCP (Nov 11), Nod from n8n Labs (Nov 12), and Apple's amortized MIPS (Nov 12 item 5). Filtered out: TermiX and Agentics.credit, Plurai Simulation, and Edge0-145B (no independent benchmark yet).
