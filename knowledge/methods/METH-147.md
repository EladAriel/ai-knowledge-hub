# METH-147: Databricks Genie Ontology is now generally available

## Summary

An ontology that agents build from everyday work and people govern, with Genie Search limited to what each user can already see, an Ontology Manager, and OntoRank to rank sources by authority. Vendor post, Nov 11. Effort: low to read, high to adopt.

## Details

Vendor claim, not independently checked: 91% of enterprise tasks passed, 1.6 times the best frontier agent, using under half the tokens, on a benchmark built with Turing. Recurring theme: Snowflake's Business Ontology (Nov 4), NVIDIA's auto-ontology (Nov 11), and Neo4j's knowledge-layer post all point at a governed semantic layer served to agents. Adopt for: Architects decide who owns definitions (people) versus learned context (agents), and rank sources by authority; Product copy the pattern of a fixed task set with target pass rates before go-live; Devs expose the ontology as a read-only MCP tool rather than pasting it into prompts.
