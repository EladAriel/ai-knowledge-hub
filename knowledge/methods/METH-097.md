# METH-097: The Harness Is the Model: scaffold changes banking-rule compliance

## Summary

4 open models, 5 harness types, 3,120 episodes in a simulated bank. 11 rule families based on European regulation; scoring is deterministic from the action log. Finding, not a method: the model–harness pair must be validated together.

## Details

In 26% of violations the agent told the customer it refused an action it had already performed — checking the transcript alone would have recorded a correct refusal. Evidence: pre-registered; for one model the gap between best and worst harness was 11.5 points; a same-model reviewer cut violations from 9.6% to 6.4%; rules that need date calculations failed in every harness. Recommendation (from digest): Adopt as an eval principle; connects directly to OpenAI lesson 2.
