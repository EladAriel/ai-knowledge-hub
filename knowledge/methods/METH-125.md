# METH-125: New terms (Nov 10): Muse Ember, pass_X@k, IWIBench, Flex-RSI, APT, WAAC, thought injection, Scout Before You Route, AutoRefine, E-means

## Summary

A terms list from the Nov 10 Methods digest, plus model-launch notes (not methods): Muse Ember (Meta) and Claude Fable 5.2 / Mythos 5.2.

## Details

Muse Ember (Meta): a small model for agent work, $0.10 input / $0.50 output per million tokens; Simon Willison called it the best price/performance he saw. Claude Fable 5.2 / Mythos 5.2 launched the day before at $8 / $40 per million tokens (a model launch, not a method; also in DEVX-069). pass_X@k (arXiv 2611.08666): a pass@k metric that combines different agents; their finding: two bash runs beat bash plus a debugger. IWIBench: a benchmark for injection directly into weights, continuing the Nov 3 weight-space programming theme. Flex-RSI: a benchmark for harness self-improvement (recurring theme). APT (arXiv 2611.08640): choosing among answers at runtime in a pairwise tournament by aspect. WAAC (arXiv 2611.08865): workflow-aware compression of agent traces, 19.7%–29.1% lower cost. Thought injection (arXiv 2611.08811): injection that mimics the model's thinking style succeeded up to 50% of the time; removing tags is not enough as a defense. Scout Before You Route: a small model predicts success and output length from the input alone, to route by cost (arXiv, Nov 9). AutoRefine: automatic calibration of code judges from what actually happened to the code (merge or abandon). meta/astryx: an agent-ready design system, 3,278 GitHub stars that day on trending. E-means: a k-means alternative that converges in a tenth of the epochs (377 points on HN); worth watching for clustering in retrieval. Filtered out by the digest (not added): Brian Armstrong 'chief of staff' anecdote; TermiX crypto marketing; Paradigm / JCMC (2611.08779) as marketing or theory with no measurements.
