# METH-182: New terms (Nov 18, methods): Control Room, obstacle omission, Elephant-Goldfish, SIM, signed requirement manifests, FieldGuide, EvoX Genesis, StarSling, Harvard PR study

## Summary

One-line mentions from the Nov 18 methods digest (no full evaluations). The recurrence check covers items through Nov 15.

## Details

OpenAI Control Room: a central system that watches model workloads and can stop them; it appears in the GPT-6.2 system card. Obstacle omission, or "silent blocker": a term starting to circulate around GPT-6.2, for when the agent does not report that it was blocked. Elephant-Goldfish Model (github.com/google/elephant-goldfish-model): a Google plugin for spec-driven development; an "elephant" that remembers context writes, and "goldfish" with no history review. Published in October and hit HN today. This lines up with the clean-context critic in Antigravity /teamwork (METH-168, Nov 15). SIM, Self-Improvement Memory (arXiv 2611.18856): memory for a harness optimizer, which stores the rationale, the prediction and the outcome of each change. Signed requirement manifests, from the paper "Signed but Not Safe": requirements pass between agents as a verbatim quote with a signed predicate. The authors report that unsafe commits under attack fell from 69.4% to 9.0% on Qwen3-8B. FieldGuide (arXiv 2611.21618): a "corpus map" for the agent; the authors report 38% fewer tokens than RAG, but on only 38 documents. EvoX Genesis: a "continuing recursive software world"; according to the report, in 1,019 episodes agents built a C compiler in Rust of about 220,000 lines. StarSling (YC): CI that improves itself with A/B tests on the runners, and opens a PR only when the improvement is statistically significant (Launch HN). Chen and Stratton, Harvard (fion.ac/jellyfish.pdf): coding agents raised the number of PRs by 35.7%, but approval time rose 56.1%; the bottleneck moved to code review.

Filtered and therefore not added: threads titled "Anthropic devs just dropped 20 repos" and "100 repos for Claude Code" (lead-gen with a wrong attribution, no primary source); "Goal engineering is about to eat harness engineering" (a new name for managing by goals and metrics, with no data or code); "GPT-6.2 Astra reached 100% on ARC-AGI-3" (a viral claim with no official source found; independent metrics instead show no coding improvement).
