# METH-070: Ramp: how to give AI context and build a company brain (playbook)

## Summary

Vendor post selling Ramp's Glass (knowledge base + connectors + owners), but the playbook is solid.

## Details

1-2 page context doc with definitions, policies, and where the truth lives per kind of fact; set permissions before connecting anything; test with 10-20 known-answer questions; give each doc section an owner; log every wrong answer as missing fact or out-of-date fact. Adopt: Architects write a source map (CRM for customers, ERP for finances); Product makes the wrong-answer log a shared queue with owners; Devs put the 10-20 known-answer questions into CI from day one.
