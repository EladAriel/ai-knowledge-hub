# METH-212: New terms (Nov 24, methods): Loop Transformer, Shirudo

## Summary

One-line mentions from the Nov 24 methods digest that did not become a full item (no full evaluations).

## Details

Loop Transformer: in GLM-5.4 from [z.ai](https://z.ai), a group of layers runs several times, so the network is deeper without extra parameters. This is the second time this week, after Inkling 2 Mini on November 21 (METH-195).

Shirudo: an open-source runtime from OpenAI and Cisco, based on eBPF, that blocks vulnerable code paths without a restart. It is still before an official release ([announcement](https://openai.com/index/introducing-shirudo/)).

FrameCheck, named as a term yesterday, is now a full item (METH-211).

Filtered and therefore not added: Claude-BugHunter, a pack of 84 skills with 2K stars and no eval; Declare, a "UI language for AI" with claims and no numbers; and an X argument that "Dario is scaring people so he can ban open source," because it is an opinion, not a method. ToRA was not repeated; it was already a term yesterday (METH-205). Nov 25 update: Z.ai published the details behind yesterday's Loop Transformer term ([announcement](https://z.ai/blog/glm-5.4)). They run a shared group of layers several times in a row, so the network is deeper without extra parameters. This is the second time this week, after Inkling 2 Mini on November 21 (METH-195). So far there is only a comparison experiment on a 30B model (for example AIME25 went from 19 to 30), and there are no numbers on the flagship model itself. The recommendation remains Watch, pending independent benchmarks.
