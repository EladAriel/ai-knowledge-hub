# METH-170: Exposure research on Lovable apps: "no technical knowledge needed" still leaves security with the customer

## Summary

Researchers scanned 159,041 Lovable projects from Common Crawl; 34,545 of them use Supabase. On 24,664 sites, records were sent already on page load. On 7,403 sites (30%), further read requests with the same key returned tables with email addresses. One finding: a forum that exposed more than 80,000 profiles and more than 200,000 private messages.

## Details

This is not a technique. It is large-scale evidence of the gap between the promise that "you don't need technical knowledge" and the security responsibility that stays with the customer. Source: crissyfield.de/research/lovable-en/. The source note was cut off after the word "especially", so no recommendation score is recorded beyond the findings above. Other items from the same day (caveman token-saving, a Tom's Hardware anecdote, DeepSeek V3 in 200 lines of Jax) were filtered out as out of scope.
