# METH-054: No single least-privilege set for agent tool authorization

## Summary

For 29.8-33.3% of Microsoft Graph tasks two minimal permission sets each allow something the other doesn't.

## Details

22,305 Graph and 23,852 Google API permissions analyzed. Six frontier models picked a minimal set 99% of the time but only 66.7% picked the one smallest on all four risk measures. Analysis of published permission lists only.
