## Details

Coca-Cola (arXiv 2611.06500, code THU-Agent/Coca-cola): compress tool output to latent tokens instead of text; claimed 70%–89% token savings. Germline execution (2611.06585): every MCP tool call runs in a clean process copy with no data, so a signed-but-malicious tool cannot leak — continues yesterday's supply-chain wave. HarnessFlow (2611.06254): MCTS search over whole harnesses; claimed +3.95 points over Meta-Harness. EvoGuard (2611.06444): pairwise classifier that decides whether to adopt a new skill version during online evolution. Turn-level Best-of-N (2611.06868): one model proposes N actions per step, another picks; +5%–10% on terminal tasks. BudgetMix RL (2611.06483): vary step budget during RL training because RL gains vanish when the budget shrinks.
