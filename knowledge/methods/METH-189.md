# METH-189: AutoRAGBench: coding agents build a RAG pipeline from scratch

## Summary

Tuning a RAG pipeline takes weeks of trial and error. AutoRAGBench gave coding agents 9 tasks, with no starter code, 6 hours and one GPU each. The best agent scored 56.1, against 44.4 for the best human-built systems. Starting from a human-built system, agents added 16.6 points on average. One full run cost about $6 to $487 in model API fees. The tasks are academic, not company data. The repo is brand new, with no stars yet, under the MIT license. Next step: check the cost table, then try one task on your own test questions. For: devs. arXiv 2611.25582; code: ZhanGHanG9991/AutoRAGBench.

## Details

Reported Nov 20, and named the same day as a term in the methods digest.

Why it matters: you could hand pipeline tuning to an agent, as long as you have a solid set of test questions.
