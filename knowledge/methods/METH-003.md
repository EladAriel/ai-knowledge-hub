## Content

**2. [Cockroach Labs: Code agent pipeline in a hospital structure](https://www.cockroachlabs.com/blog/experiment-running-hospital-code/)**
- **What it is:** A pipeline of code agents with fixed roles: triage, planning, review and release. Before any merge, planning and documentation are required. Running in production for five months.
- **Why new:** The separation of duties is mainly a new name for the planner/reviewer pattern. What is new is a long-term report from the production team, and not a demo.
- **Evidence:** According to the company, more than a million lines of code were written with only 7 reverts. Db2 support was built in less than 2 days and cost $4,172 in tokens, while Oracle support previously took 9 months. These are numbers that the company reports on itself, without external reconstruction.
- **Scores:** Effectiveness 4/5, Hype 3/5.
- **Compatibility and effort:** Relevant to any team that builds with code agents. **medium** effort.
- **Recommendation: Pilot**
