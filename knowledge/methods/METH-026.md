# METH-026: Netflix: ontology-driven observability knowledge graph

## Summary

Telemetry, alerts, deploys, incidents and incident Slack joined into one RDF/OWL graph validated with SHACL; ….

## Details

Every app must match a ~49,000-entry catalog; resolved incidents become knowledge and repeated patterns become detection rules; version the ontology like code. ….
