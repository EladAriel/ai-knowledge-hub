# METH-056: Simple harnesses beat SOP-driven agents (arXiv RCA study)

## Summary

On 90 microservice RCA cases, harnesses that don't script model calls hit 65-77% accuracy vs 16-53% for fixed-step SOP ….

## Details

Fixed steps skip exactly the deciding evidence. Raising reasoning effort changed accuracy by a few points at most but up to 7x the time. Takeaway (agent): gates should check the output (tests, findings, diff, budget), not dictate ….
