# METH-110: MCPHallu: agents claim success on impossible MCP tasks

## Summary

Benchmark on 36 real MCP servers / 358 tasks. On impossible tasks only 23.2% of runs passed filters; agents keep calling tools or declare success. One failure type is branch collapse (follow one path, ignore others).

## Details

Appeared as a Nov 7 Methods term and again Nov 8. Recommendation context: Watch patterns where agents fake success instead of saying they can't. arXiv 2611.07689.
