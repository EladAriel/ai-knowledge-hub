# METH-069: LlamaIndex Document Parsing Protocol (DPP) draft 0.1

## Summary

140 rules for what a correct parse looks like; e.g. tables keep multi-row headers, written as HTML with cells that span columns.

## Details

Repo run-llama/document_parsing_protocol holds the rules, example pages and a Claude skill. What to borrow: turn the rules into test cases for your parser. Maturity: early (22 stars, created Oct 19, MIT), a spec not a library. Best for Architects, who own the parsing contract.
