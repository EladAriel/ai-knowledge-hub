# METH-101: DeCAF (Adobe): optimize an agentic pipeline one dimension at a time

## Summary

Listed as a new name in the Nov 9 AI methods digest: optimizes an agentic pipeline dimension by dimension, with a separate code session per dimension. Per the authors, +2.58 points and 42% lower latency.

## Details

One-line mention only in the digest's new names and terms.

## Content

**New names and terms**
- [DeCAF](https://arxiv.org/abs/2611.08723) (Adobe): optimizes an agentic pipeline one dimension after another, with a separate code session for each dimension. According to the authors, 2.58 points more and 42% less latency.
- Phantom Consensus / PHANTOM-Bench: agents change a decision after an ambiguous social signal, and accuracy drops by up to 47.8 points ([cs.MA listing](https://arxiv.org/list/cs.MA/new)).
- [Reversible Multi-agent Systems](https://arxiv.org/abs/2611.09054): an agenda for keeping the ability to rein in the effects of a collective of agents that keeps learning.
- [Next-Concept Modeling](https://arxiv.org/abs/2610.14162) (Hazy Research): generating text in parallel, from coarse to fine. According to the authors, 10 to 31 times faster than diffusion models, but there is no comparison with an optimized autoregressive model.
- [ODD+LLM](https://arxiv.org/abs/2611.08932): a documentation standard for LLM agents in simulations. In 77% of the 28 papers reviewed, details on how the prompt was built were missing.
- BLA (Blind LLM Agents): decoys planted in build files against reverse-engineering agents. Only a summary on X was seen, with no verified source.
