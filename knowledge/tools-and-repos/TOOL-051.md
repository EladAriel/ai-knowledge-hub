# TOOL-051: Repos: getomnico/omni

## Summary

An open-source company brain you host yourself. It connects Drive, Slack, Jira, Confluence, HubSpot and more, and keeps each source's permissions. Search runs in plain Postgres, using both keyword and AI search. Answers come with sources, and it can run code in an isolated sandbox.

## Details

Maturity: 827 stars, Apache-2.0 license, and actively updated. The latest release was v0.1.29 on Nov 10. Permission checks on search were added on Nov 4. It started as enterprise search and now calls itself a "company agent," so this is mostly a new name.

Next step: use it as a reference build to compare with your own setup. Best for: Devs.

This is not the earlier OmniGraph repo in TOOL-011.
