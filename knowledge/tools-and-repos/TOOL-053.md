# TOOL-053: Repos: YOLOW92/pagesift

## Summary

One self-hosted Rust program turns web pages, PDFs, Office files and scanned text into Markdown, RAG chunks and JSON that tracks the source. It has an MCP server plus Python and Node packages, and can stand in for the Firecrawl and Jina Reader APIs.

## Details

Reported Nov 21. Maturity: Apache-2.0 license, 291 stars, v1.6.0 released Nov 18. It's about a month old, with 600+ commits and a very long feature list, so check it on your own docs first.
