# TOOL-042: Repos: jaredpalmer/kev, Mapika/decider, zhangfengcdt/memoir

## Summary

Decision-model gates and versioned agent memory for the feedback loop.

## Details

kev (~9.9k★, Apache-2.0, pushed Nov 3): self-hostable decision models (0.8B–27B) with calibrated yes/no and score answers—borrow as gate for injection/spam/groundedness. decider (~1.1k★, Apache-2.0): one-pass typed decisions with calibrated probabilities over HTTP, CPU versions (`pip install decider-ai`)—borrow cheap judges that sort feedback by pipeline stage. memoir (~627★, Apache-2.0, alpha): version control for agent memory (branch/commit/merge/rollback)—pairs with Memory Trap; borrow when feedback might write a bad rule.
