# TOOL-032: Repo: xberg-io/xberg (formerly Kreuzberg)

## Summary

Extracts text, tables and metadata from 100+ file formats, with OCR and code-aware chunking; library, CLI, REST API or MCP server, CPU only.

## Details

Borrow: pip install xberg, then its extract and chunk commands; caching by content hash so unchanged files aren't reprocessed; per-file timeouts. Maturity: ~9.5k stars, pushed Nov 1, v1.3.10 released Oct 13, MIT. Best for Devs.
