# TOOL-024: claude-md-management (official plugin)

## Summary

Scores your CLAUDE.md against the current codebase and writes session learnings back into it.

## Content

**[claude-md-management (official plugin)](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/claude-md-management)**, ~10 min. It scores your CLAUDE.md against the current codebase and writes session learnings back into it. In one project's weekly audit it caught wrong deploy commands. Credit: Anthropic, via @dani_avila7.
```text
/plugin install claude-md-management@claude-plugins-official
"audit my CLAUDE.md files"
/revise-claude-md
```
