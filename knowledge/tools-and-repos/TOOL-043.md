# TOOL-043: Repos: brekkylab/backlot, memgraph/ai-toolkit, axoviq-ai/synthadoc

## Summary

Local API emulators with permissions, graph agent memory, and raw-doc→wiki compilers.

## Details

backlot (223★, Apache-2.0, commits Nov 7): local fakes of Slack/Gmail/Drive/GitHub/Jira/Notion/S3 with real formats, pagination, errors, per-doc permissions—point official SDKs at one base URL; `backlot mcp --user` for one person's view. memgraph/ai-toolkit (119★, MIT): agent memory, GraphRAG, LangChain/LightRAG/MCP—borrow hook capture of agent events into a per-team graph. synthadoc (1.9k★, AGPL-3.0): raw docs→Markdown wiki with citations, contradiction flags, orphan pages, MCP—borrow ideas not code for closed-source.
